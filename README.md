# Landing Page — Buenas Prácticas de Calidad de Software

Proyecto desarrollado en **React (Vite)** utilizando **Tailwind CSS 4.1**, orientado a mostrar la aplicación de buenas prácticas de calidad, instrumentos de aseguramiento y procesos personales de desarrollo.

Incluye contenido basado en el componente formativo **“Fundamentos de Calidad de Software”** e integra marcos de trabajo como **TSP**, **PSP** y **SCRUM**, siguiendo los criterios de evaluación del proyecto.

---
## 📌 Objetivo del Proyecto
Construir una landing page informativa que presente de manera clara:
- Los **instrumentos de calidad de software**.
- La **selección de buenas prácticas** según marcos de trabajo.
- La **aplicación del proceso personal de desarrollo** (PSP).
- La **documentación del proceso de calidad**.

El sitio está diseñado como una pieza formativa, visual, moderna y totalmente responsiva.

---
## 🛠️ Tecnologías Utilizadas
- **React** (JavaScript)
- **Vite** como herramienta de construcción
- **Tailwind CSS 4.1**
- **PostCSS + Autoprefixer**
